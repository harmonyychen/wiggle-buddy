# wigglebuddy

A desktop panda that reminds you to get up and stretch, and stretches with you.

For Macs with Apple Silicon running macOS 13 or later.

## Tech Stack

Electron app built with React, Typescript, Tailwind CSS.

## Install

1. **[Download wigglebuddy 0.1.0 for Mac](https://github.com/harmonyychen/wiggle-buddy/releases/download/v0.1.0/wigglebuddy-0.1.0-arm64.dmg)** and double-click the downloaded DMG.
2. Drag the panda icon onto the **Applications** shortcut.
3. Open **wigglebuddy** from Applications. The panda will appear on your desktop.

If macOS can’t verify the developer on first launch and you trust the download, go to **System Settings → Privacy & Security**, click **Open Anyway** for wigglebuddy, and confirm. [Apple’s first-launch guide](https://support.apple.com/en-us/102445)

## How to use

Hover over the panda and click the settings icon to set how often you take breaks and how long they last. During a break, mouse and keyboard functions are frozen and the screen dims. Click **Quit** beside the countdown or press **Esc** to return to work.
