# wigglebuddy

A desktop panda that reminds you to get up and stretch, and stretches with you.

For Macs with Apple Silicon (M-series chips) running macOS 13 or later.

## Install

1. Double-click the wigglebuddy **.dmg** file.
2. Drag the panda icon onto the **Applications** shortcut.
3. Open **wigglebuddy** from Applications. The panda will appear on your desktop.

### Get the installer

1. Install [Node.js 24 or newer](https://nodejs.org/en/download) if you don’t already have it.
2. [Download the project ZIP](https://github.com/harmonyychen/wiggle-buddy/archive/refs/heads/main.zip) and unzip it, or use your existing copy.
3. Double-click **Install.command** in the project folder. It builds and opens the installer for you.

If you already have this repository open in Terminal, run `./Install.command`.

## How to use

Hover over the panda and click the settings icon to set how often you take breaks and how long they last. During a break, click **Quit** beside the countdown or press **Esc** to return to work.
